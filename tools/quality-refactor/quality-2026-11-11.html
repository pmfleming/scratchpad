Scratchpad quality refactor

Measured review of shipping search code using the locally built RustQualityLens. Baseline 7e9533d; final revision eaada2d. Three independently tested and committed production refactors, followed by test-only coverage and readability improvements.

What changed

  • 1d2521a: Six matching paths share cancellation and overflow collection. Removed an unused cancellation mode, boxed candidate iterator, redundant wrappers, and repeated test fixtures.
  • 29c178c: Result accumulation lives beside its worker and owns final status. Scoped workers borrow the query; replacement strings move directly into ordered plans.
  • 8891a2c: Serial and parallel chunk searches share bounded collection. Tests cover empty and partial batches, overflow sentinels, ordering, cancellation, failures, and worker panic shutdown.
  • ccdee90: Existing scenarios exercise public invalid-query reporting and interruptible match delivery. No production behavior changes. eaada2d names shared options so the expanded matrix remains within the existing lint limit.

Prerequisite 7e9533d fixes texture-delta disposal in headless repaint tests; both accepted quality runs include it. The failed initial coverage attempt is excluded.

Performance method and limits

Performance Lens measured production revision 8891a2c (unchanged by the final test-only commit), separately from test builds, with at least three independent resource-probe launches per workload. Workflow values are medians; display presentation is excluded. Scanner values are median per-call times from seven warmed 100 ms batches, with the saved baseline executable rerun alongside the candidate.

An initial byte-comparison change slowed multi-character case-insensitive scanning about 20%. That implementation was discarded before committing; the retained comparison uses the already-lowercase query. Final search workflow and measured resource budgets pass. Small timing changes are not treated as statistically proven improvements.

Resource measurements retain allocations, peak heap, CPU/I/O counters and trial data in the raw run artifacts. These focused checks do not establish that every application performance promise passes.

Reuse, locality and remaining risk

Cancellation cadence and result-limit semantics now have one implementation used by all six matcher paths. Result ownership is private to the worker, and replacement planning no longer builds an intermediate vector or clones replacement strings. Production .clone() call sites in the changed files fell from 21 to 18; three test glob imports and an unused Clone implementation were removed. Unsafe and lint-suppression counts did not change. This improves reuse and ownership locality without a new public API.

RustQualityLens semantic resolution remains partial and macro expansion is not fully inventoried. Leverage/locality scores are advisory. Observed worker leverage rose from 50 to 60; existing module locality scores stayed unchanged. The locality benefit is narrower result ownership inside the worker. Partial resolution limits what the graph scores establish. Policy thresholds and design-review acceptances were not changed.

The strict gate retains 36 module-threshold violations, the same count as baseline, and three required human design reviews. Fragment batching cleared its module threshold; the search-service module crossed it at 619.93 against a limit of 600 after scenario consolidation. The new scenario test raises that module’s maximum function score. This tradeoff is retained because production and whole-project complexity decrease while behavioral coverage expands and test volume shrinks. Remaining shipping hotspots include storage-health polling, snapshot persistence, chunk loading and duplicated file decoding. Measurement probes, generated artifacts and unrelated developer tooling were excluded from the implementation scope.

Verification

Full RustQualityLens measure and verify commands passed. The practices report has 19 passing checks, nine skipped checks, and no failing checks. Full tests, feature combinations, audit, and all-target Clippy with warnings denied passed. The strict gate remains failing for the module thresholds, incomplete analysis and required design reviews described above. Both measured source trees remained unchanged during their runs, and the frozen tool hashes match.
