# Undo Change Coalescing Plan

Improve undo history by coalescing short adjacent text edits into a single change when they are part of the same local typing burst. The first pass should merge single-character inserts, short word fragments, and immediate mistype/delete/retype sequences when they affect nearby ranges in the same document, occur within a short time window, and preserve a simple selection progression. The merge boundary should stay conservative: stop coalescing across cursor jumps, paste operations, multi-line edits, explicit command boundaries, file changes, focus changes, and pauses long enough to suggest a new thought.

This should improve performance by reducing the number of undo records, UI rows, ledger entries, and redraw/update work created during normal typing. It should also make the undo list more useful by showing meaningful micro-phrases or correction bursts instead of long runs of one-letter changes. Implementation can start in the document text-operation history layer, then expose the coalesced label and range to the text history UI; tests should cover normal typing, typo correction, cursor movement, paste, delete/retype, and the rule that `Ctrl+Z` still feels predictable.
